## Facade Pattern

1. Intent

   Provides a simplified interface to a complex body of code, such as a class library or a set of multiple subsystems.

2. The Context (Problem)
   You are building a Home Theater System. To watch a movie, you have to do many things manually:
   1. Turn on the TV.

   2. Turn on the Sound System.

   3. Turn on the Streaming Player.

   4. Set the TV to HDMI 1.

   5. Set the Sound System to Surround Sound.

   6. Dim the Smart Lights.
