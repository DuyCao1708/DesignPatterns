# 🏗️ Design Patterns in C# (The Gang of Four Collection)
This repository contains a complete implementation of the 22/23 classic Design Patterns described by the Gang of Four (GoF).

# 🎯 Project Goals
- Hands-on Learning: Deepening my understanding of design patterns by implementing them from scratch.

- Code Quality: Practicing SOLID principles and decoupling logic through real-world scenarios.

# 🛠️ Technical Stack

- Language: C#

- Framework: .NET 10.0

# 📂 Project Structure

Each pattern is organized into its own dedicated folder to ensure isolation and clarity:

- `README.md` explaining the **Context** to be solved.

- The core classes and interfaces that form the pattern's architecture.

# 🚀 How to use

This repository is built as a .NET Solution. You can interact with the patterns via a CLI menu or by specifying a name directly.

**1. Nagivate to the project**

```bash
cd Examples
```

**2. Run with Interactive Menu**

```bash
dotnet run
```

**3. Run a specific pattern**

```bash
dotnet run -- "bridge"
dotnet run -- "chain of respontibility"
```
